# MMMerge Vita 01.52

Download **MMMerge-Vita-01.52.vpk** below and install it directly with VitaShell. Existing players with working game data need only this VPK. The custom UI and guide are included.

- Diagnostics and timeline recording default OFF.
- The world-resolution label is hidden by default.
- The slide debug console defaults OFF; it remains available in Vita Settings > Advanced.
- The guide now starts with controls and practical play tips. Shorter explanations of worlds, saves and conversion appear near the end.
- An exact unedited older default guide is updated, with a backup. Custom guide text is preserved.

**Existing settings stay intact.** Previous testers can switch off Record diagnostics and NPC movement timings in Diagnostics, Show world resolution in Graphics, and Slide debug console in Advanced. No save format, adventure rules, controls or gameplay/performance algorithms changed.

New players: use the [Windows Asset Builder 0.3.0](https://github.com/sapouni/MMMerge-Vita/releases/tag/v01.51) to create game data from supported installed English GOG MM6/MM7/MM8. Its previously verified data set is unchanged and works with 01.52. See the [main page for installation and all controls](https://github.com/sapouni/MMMerge-Vita#installation).

**No CapUnlocker binary is included or uploaded in this release.** Download it from [GrapheneCt's original releases](https://github.com/GrapheneCt/CapUnlocker/releases) and follow the [plugin installation guide](https://github.com/sapouni/MMMerge-Vita/blob/main/docs/PLUGINS.txt). A working installation needs no plugin or firmware changes for this app update.

Validation: Standard and ThinLTO ARM builds, native launcher, final object/stack layouts, imports, package integrity, guide text bounds and eight guide-update/recovery cases passed desktop checks. Saves remain format 100134 and outside the app. Exact source, symbols, defaults and audit evidence are preserved. This is a playtest prerelease; physical testing of 01.52 is pending. No new FPS gain is claimed.
