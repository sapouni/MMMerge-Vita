# MMMerge Vita 01.51 + Windows Asset Builder 0.3.0

This is a **playtest prerelease**, not a promise of release-ready stability or a minimum framerate. The exact app is the previously delivered 01.51 candidate; adding the converter does not rebuild or change its game code. Last identity-verified physical device state: 01.50. 01.51 and freshly generated data still need physical acceptance testing.

## Choose downloads

- **MMMerge-Vita-01.51.vpk** (48 MB, recommended): install directly with VitaShell. Existing players with working game data need only this app file. Its bytes are identical to the VPK inside the testing ZIP; custom UI, guide, shaders and game libraries are included.

## Installation and saves

Keep the VPK intact and install it directly through VitaShell. Extract only the Windows builder ZIP if creating game data and read its START-HERE.txt. The main page contains installation, plugin setup and controls; the Guide is inside the game. Keep generated `engine.zip` plus `worlds/mm6.zip`, `mm7.zip`, `mm8.zip`, `mmmerge.zip` packed under `ux0:data/openyamm/assets`. Install the VPK through VitaShell.

Back up `ux0:data/openyamm` first. Update app ID MMVITA001; do not replace/delete the whole data folder. The VPK includes no personal saves/settings. No new plugin, firmware change or reboot is needed to update a working installation. Fresh devices still need compatible loaded kubridge and the shader compiler. CapUnlocker is optional; the withdrawn libperf module is not required or included.

## 01.51 changes

- Removed the ineffective per-search walk-answer memo's key/hash/storage work; exact walk validation, two-unit floor-support sampling, gaps and stairs remain.
- Dense floor probes bypass the shared floor memo under Exact path query reuse; repeated exact-XYZ snaps retain their own memo. No coarser movement sampling or height quantization.
- Fact output slots are pre-sized. Writable LOS/targeting query state still remains with its owner.
- Independent fact/decision helper pools are the default. **Shared actor helper pool (test)** restores the prior shared policy for a controlled comparison and requires game restart. This is the only new switch.
- Opt-in movement diagnosis splits work into exclusive timing buckets and counts actual post-filter/final collision inputs by query origin. Summary decoders support the new records and previous formats.

No adaptive-resolution controller, view distance, quality, simulation cadence or save-format change was made in 01.51. No new FPS improvement is claimed from desktop checks.

## Suggested testing

Vita settings → Diagnostics → Use test baseline; confirm, close/reopen the game. Standard compiler; existing fourth-core jobs/priority on; outdoor facts, tighter queries and shared pool off. Keep diagnostic recording, movement timings and timeline profiling off for normal FPS comparisons. Repeat a fixed crowded-dungeon and cannon-battle route.

Use a separate Record ON / sampled movement timings (2) run for diagnosis, timeline off. Stop recording, wait a few seconds and close the game before copying logs. Do not compare diagnostic FPS directly with capture-OFF FPS. Optional island comparison: change only Shared actor helper pool, restart, repeat the same save/route, then return off.

## Builder 0.3.0

The portable Windows tool verifies its 71 supported English GOG inputs, extracts/converts assets, applies original-source patches and supplemental merged data, converts 438 unique clips into 529 videos, verifies all 53,745 output paths, then publishes five CRC-checked archives. Originals are read only; nonempty or overlapping output folders are rejected.

Full portable conversion and independent archive comparison passed: all 53,216 nonvideo files are byte-identical to the prepared 01.51 data. Video bytes differ because they are re-encoded. All 438 unique clips, covering 529 output paths, passed full desktop decoding and original video-timeline/audio checks. An independent fresh user conversion also passed: all five archive hashes match its build report, all expected paths are present, and all nonvideo files match. The smaller MM6/MM7 ZIPs mainly reflect ZIP compression; physical loading/playback performance remains unmeasured. Nine behavioral test groups passed. GUI construction/rendering/bounds were checked; interactive clicks and physical Vita playthrough of the new generated data are not yet verified.

Most data comes from the installed originals. Supplemental data contains merged scripts/tables/scenes, additional art/voices, custom maps and residual media; its full inventory is included. Some media provenance remains untraced; this is not a claim of an original-derived-payload-free or legally cleared supplement. No original installer or original LOD/SND/VID containers are bundled.

The protected 01.45 milestone remains available locally; prior GitHub releases are not removed.
