# 01.06 R2 packaging audit

User evidence: 01.06 installs/runs under OYAM00001 but lacks LiveArea art;
OYAMART01 artwork check displays it. All four artwork files, including the
template, are identical between those packages. This supports an old-title
registration/cache problem; it does not identify the exact database flag.
R2 avoids that entry with fresh title MMVITA001, keeping OYAM00001 untouched.

Validation: only sce_sys/param.sfo, build-info.json and installation notes
differ from preserved 01.06. SFO comparison confirms every field except TITLE_ID is unchanged,
including app version and all memory flags. Every runtime, shader and artwork
file is hash-identical. Both ZIP CRC checks pass; duplicate paths rejected.
No game-data archives, saves or replacement user settings are in the VPK.
Existing debug symbols/source/configuration remain exact under the 01.06
build directories and source-at-delivery.zip. No recompilation was necessary.
