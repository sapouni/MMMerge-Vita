MMMerge Vita 01.51: manual installation

Back up ux0:data/openyamm before updates. Install MMMerge-Vita-01.51.vpk
over MMVITA001 through VitaShell. Saves and settings are outside the app.
Leave working data in place. Do not delete/replace the whole data folder.

New players: extract the Windows Asset Builder 0.3.0 and select the installed
English GOG MM6, MM7 and MM8 folders plus a new/empty output folder. It creates
engine.zip and worlds/mm6.zip, mm7.zip, mm8.zip, mmmerge.zip. Keep those five
archives packed under ux0:data/openyamm/assets. The app/VPK is separate.
No separate Python, FFmpeg, MMMerge or OpenYAMM installation is needed.

Fresh consoles need compatible kubridge loaded and libshacccg installed; see
PLUGINS.txt. A working installation needs no plugin/firmware change for 01.51.
The withdrawn libperf plugin is not supplied or required.

Use the same VPK/data on Vita and Vita3K; emulator kernel-plugin setup does not
apply. Vita compatibility is the priority and the new generated set still needs
a physical playthrough. Last identity-verified device state was 01.50.

Vita settings -> Diagnostics -> Use test baseline, confirm, close/reopen GAME.
Keep captures off for ordinary play; separately recorded diagnosis can be slower.
Full instructions: README.md, docs/ASSET-BUILDER.md and the release notes.
