# MMMerge Vita Asset Builder 0.3.0

Use the portable Windows ZIP from the [Releases page](https://github.com/sapouni/MMMerge-Vita/releases). It creates all required runtime archives from installed supported English GOG MM6/MM7/MM8 plus bundled project patches/supplemental content. The separate game ZIP supplies the VPK.

The source here covers the UI, isolated-runtime launcher, read-only extraction, exact source-linked patches, atomic output publication, verification and developer packaging scripts. Large conversion resources and bundled runtimes are release assets, not Git history. Developer resource-preparation scripts need their reference manifests and asset inputs; they are not a fresh-clone user setup. See [user instructions](../docs/ASSET-BUILDER.md).

No source is relicensed by this addition. Original-game and upstream/dependency notices remain applicable; resource provenance is described in the package inventory.
