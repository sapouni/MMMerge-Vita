# Source attribution and licensing status

The upstream OpenYAMM README currently states that no license has been declared.
This snapshot does not add a blanket license or relicense upstream work.
See https://github.com/pjasicek/openyamm for current upstream terms and attribution.
Third-party components retain their own LICENSE/COPYING/NOTICE files in the dependency folders.
Original game-content archives are not included. The supplied LiveArea artwork is retained for this
private port project; no claim of ownership over the original Might and Magic artwork is made.

Repository visibility must remain private initially, as requested by the owner.
